# ArbitrageTable

Таблица funding arbitrage opportunities.

## Реальная реализация

```text
frontend/FundingMonitor.Web/src/features/arbitrage/ArbitrageTable.tsx
```

## Props

```ts
interface ArbitrageTableProps {
  data: FundingArbitrageDto[];
  filtersKey?: string;
  isLoading?: boolean;
  onArbitrageClick?: (symbol: string, exchanges: string[]) => void;
}
```

## Поведение

- Группирует opportunities по символу.
- Ширины семи колонок заданы через `colgroup` и `table-fixed`, не зависят от значений или страницы. При ширине панели меньше 1000 px появляется горизонтальная прокрутка; место вертикальной полосы прокрутки зарезервировано.
- Показывает лучшую связку первой.
- Позволяет раскрывать дополнительные связки по тому же символу.
- Сортирует по `aprSpread`, `priceSpreadPercent`, `fundingRateSpread`, `symbol`.
- После группировки и сортировки разбивает результат на страницы по 25 монет; доступны размеры 50 и 100. Все связки одной монеты остаются в одной группе на одной странице.
- Показывает диапазон монет, общее количество и переходы между страницами. Смена фильтров, сортировки или размера страницы возвращает на первую страницу; при уменьшении списка текущая страница ограничивается последней доступной.
- Фоновое обновление сохраняет страницу, сортировку, раскрытые группы и прокрутку. При переходе между страницами прокрутка таблицы возвращается вверх.
- `useArbitrageRates` использует TanStack Query. Общий таймер dashboard каждые 5 секунд запускает запрос арбитража одновременно с запросом текущих ставок; очередной запрос не дублирует незавершённый. В скрытой вкладке опрос приостанавливается, при возвращении или восстановлении сети обе таблицы запрашиваются совместно.
- Вместо ручного обновления используется переключатель «Автообновление», включённый по умолчанию. Пауза прекращает таймер и обновления при фокусе/восстановлении сети; запрос уже в работе может завершиться. Изменение фильтров загружает соответствующие данные и при выключенном таймере.
- Ошибки не удаляют последний успешный результат: сообщение отображается над dashboard, в автоматическом режиме выполняются две повторные попытки с задержкой 2 секунды.
- Пагинация клиентская: API возвращает полный отфильтрованный список связок. Размер ответа не уменьшается.
- Монета, биржи, минимальный APR, лимит неблагоприятного спреда по ценам входа и переключатель одинаковых интервалов передаются вместе в `GET /api/v1/Arbitrage`. При первом открытии и после сброса критерии пусты. Выбранные фильтры сохраняются в `localStorage` браузера и восстанавливаются после перезагрузки страницы.
- Основная пара группы выбирается по APR среди пар из ответа. В основной строке группы и в раскрытых строках колонка «Цена в стакане» показывает одну цену входа на биржу (bid шорта или ask лонга). Спред в USDT равен `BidShort − AskLong`. Процент рассчитан от среднего двух цен входа и используется для сортировки и фильтра.
- Все Bid/Ask одного символа в полном загруженном `data` задают единый формат цен для основной и раскрытых связок. Карта вычисляется до группировки, сортировки и пагинации, без учёта спреда. Новый ответ пересчитывает формат; исключённые серверными фильтрами данные не участвуют.
- Базовая точность: от 1000 — 2 дробных знака, от 1 до 1000 — 4, меньше 1 — 5 значащих цифр. Для символа берётся максимальное требуемое число дробных знаков; все цены дополняются нулями до общей точности. Усечение выполняется к нулю без округления, исходные значения сохраняются.
- Если все ненулевые цены символа меньше 0,001, ведущие дробные нули сжимаются нижним индексом: `0.0002323` → `$0,0₃23230` при локали ru-RU. Индекс обозначает количество ведущих дробных нулей. При пересечении порога 0,001 весь символ использует обычную десятичную запись. Разделители соответствуют локали браузера.
- Денежный спред использует тот же формат, что и цены символа, включая число дробных знаков и режим сжатия; индекс учитывает собственные ведущие нули спреда. Знак денежной величины берётся из `priceSpread`. Спред меньше последнего видимого разряда может отображаться нулём с общей точностью и без знака; исходная величина доступна полностью. Процентный спред, APR и funding spread сохраняют прежний формат и расчёты.
- Общий компонент `PriceValue` показывает полную десятичную запись по наведению и фокусу. Клик, Enter или Space копируют исходное доступное во frontend число с точкой, без валюты и группировки, и сообщают результат через `role="status"`. Копирование цены или денежного спреда не запускает переход по строке и не меняет фильтры dashboard.
- При клике может синхронизировать основной фильтр dashboard через `onArbitrageClick`.
- Показывает exchange links `exchangeAUrl` и `exchangeBUrl`.
